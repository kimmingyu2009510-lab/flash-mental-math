덧셈 빨리 하는 법

덧셈은 모든 암산의 바탕입니다. 큰 수를 한 번에 더하려 하지 않고 나누거나 맞추면 실수가 눈에 띄게 줄어듭니다.

덧셈 요령이 필요한 이유

암산에서 덧셈은 가장 자주 쓰는 연산입니다. 곱셈을 쪼개서 계산할 때도, 뺄셈을 보정할 때도, 퍼센트를 구할 때도 마지막 단계에는 결국 덧셈이 나옵니다. 그래서 덧셈이 느리거나 불안하면 다른 연산도 함께 느려집니다.

덧셈에서 틀리는 가장 큰 이유는 계산 자체가 어려워서가 아니라 받아올림을 놓치기 때문입니다. 숫자를 머릿속에 오래 들고 있을수록 놓치기 쉽습니다. 그래서 아래 요령의 핵심은 모두 ‘머릿속에 들고 있어야 할 숫자를 줄이는 것’입니다.

원리: 왜 이렇게 계산해도 되는가

우리가 쓰는 10진수는 자리마다 값이 정해져 있습니다. 47은 40과 7을 합친 수이고, 356은 300과 50과 6을 합친 수입니다. 덧셈에는 순서를 바꿔도 결과가 같다는 교환법칙과, 묶는 방법을 바꿔도 결과가 같다는 결합법칙이 성립합니다. 그래서 수를 자리별로 나누어 따로 더한 뒤 합쳐도 같은 값이 나옵니다.

또 하나의 원리는 ‘더한 만큼 빼면 값이 변하지 않는다’는 것입니다. 어떤 수에 3을 더했다면 마지막에 3을 빼 주면 원래의 값이 됩니다. 아래의 보정 요령이 이 원리를 이용합니다.

요령 1: 자리별로 나누어 더하기

큰 자리끼리, 작은 자리끼리 따로 더한 뒤 합친다.

두 자리 수 이상의 덧셈에서 가장 기본이 되는 방법입니다. 십의 자리는 십의 자리끼리, 일의 자리는 일의 자리끼리 더합니다.

예 1) 47 + 38
40 + 30 = 70
7 + 8 = 15
70 + 15 = 85
예 2) 356 + 287
300 + 200 = 500
50 + 80 = 130
6 + 7 = 13
500 + 130 = 630, 630 + 13 = 643

자릿수가 늘어나도 방식은 같습니다. 다만 중간 결과가 많아지므로 계산하는 순서를 정해 두는 것이 좋습니다. 큰 자리부터 더하면 전체 크기를 먼저 알 수 있어서 어림으로 검산하기도 쉽습니다.

요령 2: 10의 배수로 맞추고 보정하기

더하는 수를 딱 떨어지는 수로 올려서 더한 뒤, 올린 만큼 빼 준다.

58 + 37에서 37을 40으로 올리면 58 + 40 = 98이 됩니다. 3을 더 더한 셈이므로 마지막에 3을 빼서 95입니다. 딱 떨어지는 수에 더하는 계산은 받아올림이 거의 없어서 훨씬 편합니다.

예 1) 58 + 37
58 + 40 − 3 = 98 − 3 = 95
예 2) 197 + 248
200 + 248 − 3 = 448 − 3 = 445
예 3) 399 + 126
400 + 126 − 1 = 526 − 1 = 525

보정 방향이 헷갈리면 ‘올려서 더했으니 나중에 뺀다’고 기억하면 됩니다. 반대로 내려서 더했다면 나중에 그만큼 더합니다.

요령 3: 앞자리부터 이어서 더하기

한쪽 수는 그대로 두고, 다른 쪽 수를 큰 자리부터 하나씩 이어서 더한다.

종이에 쓸 때는 일의 자리부터 더하지만, 암산에서는 큰 자리부터 하는 편이 편합니다. 한쪽 수를 기준으로 삼고, 다른 쪽 수를 백의 자리, 십의 자리, 일의 자리 순서로 더해 갑니다. 이렇게 하면 기억해야 할 값이 ‘지금까지의 합’ 하나뿐입니다.

예 1) 468 + 275
468 + 200 = 668
668 + 70 = 738
738 + 5 = 743
예 2) 1,250 + 3,780
1,250 + 3,000 = 4,250
4,250 + 700 = 4,950
4,950 + 80 = 5,030

이 방법은 중간 값을 하나만 기억하면 되기 때문에 받아올림을 놓칠 가능성이 낮습니다.

요령 4: 합이 10이나 100이 되는 수끼리 묶기

여러 수를 더할 때는 합이 딱 떨어지는 짝을 먼저 묶는다.

교환법칙과 결합법칙 덕분에 여러 수를 더할 때는 순서를 마음대로 바꿔도 됩니다. 합이 10, 100처럼 딱 떨어지는 짝을 먼저 찾으면 계산이 단순해집니다.

예 1) 14 + 27 + 6 + 13
(14 + 6) + (27 + 13)
= 20 + 40 = 60
예 2) 25 + 48 + 75 + 12
(25 + 75) + (48 + 12)
= 100 + 60 = 160

연습 예제

위의 요령을 섞어서 직접 계산해 보세요. 풀이를 먼저 가리고 풀어 본 뒤에 확인하면 좋습니다.

예제 1) 129 + 456
129를 130으로 올려서 130 + 456 = 586
1을 더 더했으므로 586 − 1 = 585
예제 2) 78 + 65
(70 + 60) + (8 + 5)
= 130 + 13 = 143
예제 3) 2,468 + 1,357
2,468 + 1,000 = 3,468
3,468 + 300 = 3,768
3,768 + 50 = 3,818
3,818 + 7 = 3,825
예제 4) 36 + 19 + 64 + 81
(36 + 64) + (19 + 81)
= 100 + 100 = 200

자주 하는 실수

  • 받아올림 누락: 7 + 8 = 15에서 올림수 1을 잊고 5만 남기는 실수입니다. 큰 자리부터 이어서 더하면 줄어듭니다.
  • 보정 방향 혼동: 올려서 더했는데 보정할 때 다시 더해 버리는 실수입니다. 올렸으면 빼고, 내렸으면 더합니다.
  • 자리 섞임: 세 자리 수와 두 자리 수를 더할 때 백의 자리와 십의 자리를 섞어 버리는 실수입니다. 자리별로 나눠서 쓰는 습관이 도움이 됩니다.
  • 서두름: 중간 결과를 확인하지 않고 끝까지 가는 경우입니다. 각 단계의 결과를 속으로 한 번 되뇌면 틀린 지점을 빨리 찾을 수 있습니다.
